# YouTube UI Clone 📺

This is a static front-end clone of the YouTube homepage. I built this project side-by-side while learning HTML and CSS to practice translating a complex, real-world design into code. 

## 🎯 Learning Objectives
Building this clone helped me practice and understand:
* **CSS Grid:** Structuring the main video thumbnail grid.
* **Flexbox:** Aligning items in the top navigation bar and side menu.
* **Semantic HTML:** Using proper tags for better structure and accessibility.
* **Hover Effects & Transitions:** Recreating the interactive feel of the YouTube UI.

## 🛠️ Technologies Used
* HTML5
* CSS3

## 🚀 How to Run
Simply download or clone the repository and open `index.html` in your browser. No server or build tools are required!
